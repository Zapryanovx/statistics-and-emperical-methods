# Теория на вероятностите и математическа статистика

## Съдържание и стил

- Всяка глава съответства на една тема от курса.
- Дефинициите, свойствата/теоремите, следствията и забележките са
  оформени в цветни кутии за по-лесна навигация:
  - :orange_circle: **Дефиниция** - кехлибарено
  - :large_blue_circle: **Теорема / Свойство** - синьо
  - :green_circle: **Следствие** - зелено
  - :purple_circle: **Забележка** - лилаво
  - :white_circle: **Доказателство** - сиво

## Компилиране

Компилира се с обикновен **pdfLaTeX** (кирилицата е през
`babel` + `fontenc` с T2A кодировка, без нужда от системни шрифтове).

```bash
cd Theory
pdflatex main.tex
pdflatex main.tex   # втори път за съдържание/препратки
```

Ако нямате локална LaTeX инсталация, файловете от `Theory/` могат да се качат
директно в [Overleaf](https://www.overleaf.com/) - компилаторът по
подразбиране (pdfLaTeX) работи без промяна на настройки.

Проверено с локална компилация (MiKTeX, pdfLaTeX).

## Структура

```
Theory/
  main.tex           - главен файл, включва всички глави
  preamble.tex       - цветова палитра, кутии, стилове на заглавия

  chapters/ch02.tex  - Тема 2: Вероятност и вероятностно пространство
  ...
  chapters/ch16.tex  - Тема 16: Линейна регресия
```
